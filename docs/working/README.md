# Fases en curso

Un archivo `faseN-nombre.md` por fase activa. La plantilla está en
[`../README.md`](../README.md).

Idealmente hay **una sola** fase acá. Dos fases abiertas en paralelo solo tienen sentido si
tocan repos distintos y no comparten esquema.

Cuando una fase cumple todos sus criterios de cierre, se mueve a
[`../archived/`](../archived/) con `git mv` y se anota en [`../continue.md`](../continue.md).
